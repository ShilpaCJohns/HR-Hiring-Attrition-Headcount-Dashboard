
# HR Hiring, Attrition & Headcount Dashboard

## 1. Project Overview

This project is an Excel-based HR Analytics Dashboard designed to analyze workforce headcount, employee hiring and attrition.

The objective is to convert employee data into meaningful HR insights through interactive visualizations and key performance indicators (KPIs).

## 2. Business Objective

Organizations need accurate workforce data to monitor employee movements and understand workforce composition.

This dashboard aims to help HR professionals:
- Monitor employee headcount.
- Track hiring trends.
- Analyze employee attrition.
- Understand workforce distribution.
- Support data-driven HR decisions.

## 3. Key HR Metrics

- Total Employee Headcount
- Hiring Analysis
- Employee Attrition
- Workforce Distribution
- Gender Distribution
- Employee Status Analysis
